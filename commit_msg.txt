Implement credential ZK smart contract and generate compiler bindings

- Created the core zero-knowledge smart contract in contract/src/credential.compact with three ZK circuits:
  * issueCredential: for universities to publish secure cryptographic grade commitments on-chain.
  * proveEligible: for students to locally generate proofs that their CGPA meets the opportunity threshold.
  * checkEligibility: for employers to verify eligibility results as a binary PASS/FAIL status without seeing raw grades.
- Wrapped key ledger lookups and insertions with disclose() annotations to satisfy Compact compiler witness disclosure checks.
- Configured package dependencies, tsconfig, and a workspace build script inside the contract directory.
- Compiled the contract and successfully generated TypeScript bindings, intermediate representations (ZKIR), and proving/verifying keys.
- Added a root .gitignore file to exclude node_modules, build directories (dist/), system logs, and local environment state files.
