Implement academic credential attestation Express server

- Created Express API workspace at api/ to handle off-chain credentials attestation.
- Developed api/src/server.ts with a POST /api/credential/sign endpoint that generates deterministic SHA-256 HMAC signatures (commitments) of student IDs and grades.
- Created api/src/index.ts to load environment configurations via dotenv before booting the server.
- Added api/.env.example to define key environment variables (ISSUER_PRIVATE_KEY and PORT) and created a default local .env file.
- Established Typescript compiler settings in api/tsconfig.json and workspace configuration in api/package.json.
- Verified TypeScript compilation builds the server without warnings or errors.
